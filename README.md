# 🎵 YouTube Audio Player (CLI)

Легковесный консольный плеер для потокового воспроизведения аудио с YouTube. 

Главная особенность проекта: **мгновенный старт воспроизведения без скачивания файла на диск**. Это позволяет слушать даже 12-часовые lo-fi стримы, не занимая место на SSD и не тратя время на загрузку.

## ✨ Возможности

- 🚀 **Потоковое воспроизведение:** Получение прямой ссылки на аудиопоток и передача её в системный плеер (`mpv`).
- ⏱ **Живой консольный таймер:** Обновление прогресса воспроизведения в реальном времени с использованием ANSI escape-кодов (без спама новыми строками).
- 🔒 **Обход защит YouTube:** Корректная работа с cookies браузера и JS-challenge (через `remote_components`), что гарантирует стабильное получение форматов.
- 🧹 **Чистота системы:** Использование временных данных в памяти, отсутствие мусора на диске после прослушивания.

## 🛠 Требования

Для работы приложения необходимы:
1. **Python 3.10+** (протестировано на 3.13)
2. Менеджер пакетов **[uv](https://docs.astral.sh/uv/)**
3. Системный плеер **[mpv](https://mpv.io/)** (или `ffplay` из пакета `ffmpeg`)
4. Браузер (Firefox/Chrome) с активной сессией на YouTube для извлечения cookies.

> **Для пользователей Arch Linux / CachyOS:**
> Убедитесь, что `yt-dlp` установлен глобально, чтобы `mpv` мог его найти:
> ```bash
> sudo pacman -S mpv yt-dlp
> ```

## 🚀 Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/L1ghtdevelop/youtube-audio-player.git
   cd youtube-audio-player
   ```

2. Синхронизируйте зависимости через `uv`:

   ```bash
   uv sync
   ```

3. Запустите плеер, передав ссылку на видео:

   ```bash
   uv run youtube-audio-player "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
   ```

## ⚙️ Как это работает (Архитектура)

Проект построен на принципе разделения ответственности:

- **Сбор метаданных:** Библиотека `yt-dlp` используется в режиме `download=False` для извлечения названия, длительности и, самое главное, прямой URL-ссылки на лучший доступный аудиопоток (`bestaudio`).
- **Неблокирующий запуск:** Модуль `subprocess.Popen` запускает `mpv` в фоновом режиме с флагами `--no-video` и перенаправлением `stdout`/`stderr` в `DEVNULL`. Это позволяет Python-процессу не блокироваться и продолжать работу.
- **Консольный UI:** Цикл `while process.poll() is None:` отслеживает статус плеера. С помощью комбинации `\r` (возврат каретки) и ANSI-кода `\033[K` (очистка строки) реализуется эффект обновляющегося прогресс-бара в одной строке терминала.
